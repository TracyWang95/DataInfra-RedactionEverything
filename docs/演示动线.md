# 客户演示动线（百万级合同版）

时长 ~20 分钟 ｜ 环境：生产双卡 5090（或客户现场同拓扑）｜ 演示账号提前备好：管理员 1 个 + 已授「批量确认」的审核员 1 个

## 演示前 10 分钟检查单

1. `curl localhost:8000/health/services` → `all_online: true`（左下角服务面板全绿、双卡显存正常）
2. 跑一遍 `python e2e/smoke_routes.py`（14 路由冒烟，有头 Chrome 30 秒）
3. 演示语料就位：`e2e/corpus/{legal,medical,finance,gov}/`（四行业各若干份，含真值）
4. 断网备案：全栈本地部署，演示中可当场拔网线证明"数据不出域"

## 动线（按客户痛点递进）

### 第 1 幕 · 单文件见效（3 分钟）
`单次处理` 拖入一份法律合同（corpus/legal/contract_01.txt）→ 秒级识别 → 左右对比 + 实体清单 →
勾掉一项再勾回（展示人工可控）→ 确认匿名化 → 下载成品。
**话术锚点**：所有模型本地 GPU，右下角版本戳=交付可追溯。

### 第 2 幕 · 批量与人效（6 分钟）
`批量处理` 选「法律行业」预设 → 上传 10 份混合文件 → 批量识别（讲：实测 29.2 份/分钟，万级已在客户环境验证）→
审阅页演示 **← / → + Ctrl+Enter 键盘流**（审核员一天几百份的日常）→
切管理员给审核员开「批量确认」权限 → 回来点 **「一键确认剩余 N 份」**（讲：6720 份实测秒回、后台批量事务）→
进导出，>200 份自动异步分卷（当场点「预估」秒回大小）。

### 第 3 幕 · 库表与数据库（4 分钟）
`库表处理` 导入客户敏感表样例 CSV → **「生成字段策略」**（身份证自动掩码/姓名令牌化，逐列可改）→
确认+保存 → 交付导出 ZIP（含 quality-report.json）。
**话术锚点**：也可直连 PostgreSQL/MySQL 读取；十万行 4.3 秒分卷导出。

### 第 4 幕 · 企业治理收口（5 分钟）
`系统设置`：五角色矩阵（现场让"只读"账号试图上传→被拒）→ 审计日志（检索刚才的操作，导出 CSV）→
服务监控（双卡显存+数据盘水位）→ 讲数据保留策略与升级机制（备份→健康门禁→自动回滚，已真机验证）。

### 收尾 · 数据说话（2 分钟）
打开 `docs/性能与质量白皮书.md`：四行业 identity 召回 100% 记分卡 + 吞吐阶梯 + 复验方法学——
**"这些数字您的环境可以当场复跑"**（`e2e/industry_recall.py`）。

## 常见现场问答口径

- **"识别漏了怎么办？"** → identity 类门槛 100% 进 CI，漏检=构建失败；且人工审阅是流程内置环节，批量确认是授权行为。
- **"数据库是什么？"** → 见白皮书 §6：嵌入式引擎匹配本地交付形态，PG/达梦适配在路线图，库表模块已直连主流库。
- **"能不能私有化断网跑？"** → 演示中已拔网线证明；全部模型本地。
- **"和在线脱敏 SaaS 比？"** → 数据不出域 + 视觉链路（公章/签字/手写）+ 行业包验收轨，三点都是 SaaS 给不了的。

### 加演幕（第二轮能力，穿插在第 2/4 幕）
- 第 2 幕批量配置时顺手输入水印文案 → 导出成品带「仅供XX项目使用」平铺水印（法律/金融客户必问）
- 演示中切走页签 → 批量完成时系统通知弹出（"跑长任务不用盯屏"）
- 第 4 幕系统设置多看一眼「授权许可」tab：席位/到期/离线续期（商业交付的正规感）；顺带讲 LDAP 对接与白标能力（四个参数换牌）

### 数据安全幕（第三轮能力，可替换第 4 幕后半）
- 当场删一个文件 → 打开回收站 → 还原（"误删不再是事故"）
- 服务监控看备份新鲜度（每小时全量热备+文件树增量，恢复有停服 CLI 演练过）
- 授权许可 tab 旁讲 API 密钥：客户系统对接不用共享人的账号
