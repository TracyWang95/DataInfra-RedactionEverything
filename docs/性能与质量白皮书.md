# 数据匿名化流通利用基础设施 · 性能与质量白皮书

版本：v1.0（2026-07-04）｜ 适用版本：平台 v1.0.0 ｜ 数据来源：双卡 RTX 5090 生产环境实测

---

## 1. 平台概述

本平台面向法律、医疗、金融、政务场景，提供文档（Word/PDF/图片/扫描件）与库表（CSV/Excel/JSONL/SQLite/数据库直连）两类数据的本地化匿名化处理。全链路数据不出域：识别与打码所需的 OCR、语义、视觉三类模型全部本地 GPU 部署，无任何外部 API 依赖。

## 2. 识别质量（黄金语料实测）

采用逐项标注真值的行业黄金语料，在生产环境完整识别管线上实测。判定标准：
**identity 类（姓名/证号/电话/卡号等直接标识符）漏检不可接受，门槛 100%**；standard 类（地址/机构/邮箱等）门槛 85%；行业专项标识符单列观察。

| 行业语料 | identity 召回 | standard 召回 | 行业专项召回 | 类型标注正确率 |
|---|---|---|---|---|
| 法律（合同/协议 5 份，46 实体） | **31/31 = 100%** | 15/15 = 100% | — | 100% |
| 医疗（病历/报告 4 份，33 实体） | **19/19 = 100%** | 7/7 = 100% | 病案号/住院号/门诊号 7/7 = 100% | 97% |
| 金融（审批/流水/尽调 3 份，28 实体） | **17/17 = 100%** | 8/8 = 100% | 客户号/商户号/流水号 5/5 = 100% | 100% |

质量回归机制：以上语料与门槛作为验收轨常驻代码库，任何识别管线改动导致召回下降即构建失败——识别质量与代码一样受版本控制保护。

## 3. 吞吐性能（60 文件混合语料基准）

基准语料：扫描 PDF / 电子 PDF / 图片 / 文本混合。三轮优化实测：

| 轮次 | 文件/分钟 | 页/分钟 | 说明 |
|---|---|---|---|
| 基线 | 25.78 | 38.67 | 初始生产配置 |
| 并发优化 P0 | 27.77 | 41.66 | 拆除全局串行锁，NER 并发闸门 |
| 并发优化 P1 | **29.2** | **43.81** | OCR 每卡双实例、least-inflight 负载均衡、调度上限放宽 |

单文件时延：文本类约 1-3 秒/份；扫描件 warm 状态约 1.5-3 秒/页（含 OCR、语义、视觉三管线）。

## 4. 规模化能力（万级实测）

- **万级批量**：单任务 10,000+ 文件支持；6,720 份实测批量（生产客户场景）全流程通过
- **批量一键确认**：万级任务后台批量事务处理，接口秒回，进度实时可见
- **异步分卷导出**：导出大小预估秒回（误差 <1%，实测 0.1%）；每卷 ≤2GB 自动分卷；断点续传下载
- **十万行库表**：120,000 行导出实测 4.3 秒、内存峰值 80MB、xlsx 自动按 5 万行分卷（Excel 秒开）
- **上传弹性**：4 路并发上传；大文件分块断点续传；断网后一键重试，幂等保证绝不重复入库

## 5. 安全与合规

- **认证与会话**：JWT + httpOnly Cookie，登录限速与锁定，令牌吊销与全设备下线
- **角色矩阵**：管理员 / 审核员 / 操作员（不可确认审核）/ 只读，服务端统一强制；批量确认为逐人授权的独立权限
- **审计日志**：上传/确认/导出等敏感操作全量留痕，管理员可按人/动作/关键字检索并一键导出 CSV
- **文件安全**：magic bytes 校验防伪造扩展名、病毒扫描、路径穿越防护、租户隔离（用户仅见自己的文件与任务）
- **传输与存储**：本地部署数据不出域；上传原件与匿名化成品目录分离，支持独立备份策略

## 6. 数据库与部署形态说明（选型口径）

平台元数据默认采用嵌入式存储引擎（WAL 模式），与单机本地化交付形态匹配：零数据库运维、开箱即用，实测支撑万级任务与十万行导出无瓶颈。产品路线图包含数据层抽象与 PostgreSQL / 达梦 / openGauss 适配选项，供客户 IT 规范或信创环境要求时启用。库表处理模块已支持直连客户侧 PostgreSQL / MySQL 等主流数据库读取源数据。

## 7. 企业集成能力（第二轮新增）

- **成品水印**：图像/PDF 输出可选平铺半透明文案（如「仅供XX项目使用」），中文渲染内置字体不依赖服务器字体；多页 TIFF 逐帧保留；单文件与批量均可配置，留空即关闭
- **任务完成通知**：批量识别完成/批量确认落定即时提醒；页签在后台时发送系统通知，长任务无需盯屏
- **离线 License 授权**：Ed25519 签名证书（客户名/到期日/席位数/行业包），启动校验+每日复检+文件热更新；到期进入只读宽限期而非硬停机（客户数据永不被锁死）；管理员可在界面内上传续期证书，全程离线
- **LDAP / AD 对接**：企业目录统一认证（直绑/搜索绑定双模式、组→角色映射、TLS 强制）；管理员本地 break-glass 通道保证目录故障时可登录；默认关闭，环境变量启用
- **白标交付**：产品名/标语/Logo/主色四个构建参数整站换牌，交付客户品牌版本无需改源码

以上能力默认关闭（水印/通知除外），存量部署行为零变化；启用均为配置级操作。

## 8. 验证方法学

本白皮书全部数字来自生产环境（双卡 RTX 5090）自动化实测，测试资产随代码库版本化：

- 吞吐：`backend/scripts/benchmark_throughput.py`（60 文件混合语料，零埋点，读取管线自身性能记录）
- 质量：`e2e/industry_recall.py` + `e2e/corpus/{legal,medical,finance}/`（黄金语料+逐项真值）
- 功能：7 条端到端自动化路径（真实 Chrome 驱动生产界面：单文件/批量五步/库表全链路/异步导出/权限矩阵/改密/全路由冒烟）

以上均可在客户环境复跑复验。
